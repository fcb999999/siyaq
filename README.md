# سياق — عارض المحتوى المتسلسل

> رتّب محتواك.. واعرضه بسياق

برنامج سطح مكتب لويندوز يعرض **الصور والفيديو وملفات PDF والنصوص** في عرض واحد متسلسل،
بحيث تتنقّل بينها بملء الشاشة **دون الخروج من العرض** عند تغيّر نوع الملف.

---

## التشغيل

انقر مرّتين على أيقونة **سياق** على سطح المكتب.

إن لم تكن موجودة (أو نقلتَ مجلد البرنامج) فأنشئها بأمر واحد:

```bash
npm run shortcut
```

يبني أيقونة `.ico` من الشعار ثم ينشئ الاختصار على سطح المكتب. وهو يشير مباشرةً
إلى `electron.exe` لا إلى ملف `.bat`، فلا تظهر نافذة أوامر سوداء عند التشغيل.
ولإضافته إلى **قائمة ابدأ** أيضاً:

```bash
set SYAQ_START_MENU=1 && npm run shortcut
```

وتبقى الطرق الأخرى متاحة: ملف `تشغيل سياق.bat` أو الأمر `npm start`.

> إن نقلت مجلد البرنامج إلى مكان آخر، أعد تشغيل `npm run shortcut` ليُحدَّث مسار الاختصار.

## كيف تستخدمه

1. **أضف المحتوى** — زر «إضافة ملفات» أو «إضافة مجلد»، أو اسحب الملفات وأفلتها في النافذة.
2. **رتّبه** — اسحب البطاقات بالفأرة، أو انقر على **رقم البطاقة** واكتب الرقم الذي تريده فينتقل إليه.
   وهناك ترتيب تلقائي جاهز (بالاسم، بالتاريخ، بالنوع، بالحجم، عكسي، عشوائي).
3. **اعرض** — زر «ابدأ العرض» يفتح ملء الشاشة من أول عنصر (أو من العنصر المحدد).
4. **احفظ** — زر «حفظ العرض» يحفظ الاسم مع الترتيب ومسارات الملفات.
   في أي وقت لاحق افتح البرنامج واضغط «فتح» على العرض من الشريط الجانبي، فيرجع بنفس الترتيب
   ما دامت الملفات في أماكنها. أي ملف نُقل أو حُذف يظهر معلَّماً باللون الأحمر،
   ويمكنك تحديد مكانه الجديد من زر 🔎 على البطاقة.

## اختصارات لوحة المفاتيح داخل العرض

| المفتاح | الوظيفة |
|---|---|
| ◀ يسار | العنصر التالي |
| ▶ يمين | العنصر السابق |
| Space | تشغيل/إيقاف الفيديو، أو الانتقال للتالي في الصور |
| Esc | إنهاء العرض |
| F أو F11 | تبديل ملء الشاشة |
| Home / End | أول عنصر / آخر عنصر |
| G | شبكة المحتوى للانتقال السريع |
| ١…٩ | الانتقال إلى العنصر برقمه |
| + / − / 0 | تكبير / تصغير / إعادة الحجم |
| ↑ / ↓ | رفع / خفض الصوت |
| M | كتم الصوت |

> اتجاه الأسهم قابل للعكس من **الإعدادات** إن كنت تفضّل النمط الإنجليزي.

### الفأرة
- **النقر** على نصف الشاشة الأيسر = التالي، والأيمن = السابق (قابل للتغيير من الإعدادات).
- **الزر الأيمن** = العنصر السابق.
- **العجلة** = تنقّل، أو تكبير الصورة — حسب إعدادك.
- في ملفات PDF والنصوص تُعطَّل مناطق النقر تلقائياً حتى تتصفّح المستند براحة.

### اختصارات خارج العرض
`Enter` بدء العرض · `Delete` إزالة المحدد · `Ctrl+S` حفظ · `Ctrl+A` تحديد الكل ·
`Ctrl + سهم` تحريك العنصر المحدد في الترتيب

## الإعدادات

- **اتجاه التنقل بالأسهم** — عربي (يسار = التالي) أو إنجليزي.
- **تشغيل الفيديو والصوت عند الانتقال إليه**:
  - **تلقائي** — يبدأ من نفسه فور وصولك إليه في العرض.
  - **يدوي** — يقف عند أول لقطة ويظهر زر تشغيل كبير في المنتصف، تضغطه أو تضغط مفتاح المسافة.
- **أشرطة التحكم داخل العرض**:
  - **تظهر عند تحريك الفأرة** وتختفي بعد سكونها (الوضع الافتراضي).
  - **مخفية نهائياً** — لا يظهر الشريط العلوي ولا السفلي أبداً، ولا بحركة الفأرة ولا بالنقر،
    فتبقى الشاشة للمحتوى وحده. التنقّل بالأسهم والفأرة كالمعتاد، و**الخروج بـ `Esc`**.
- سلوك النقر بالفأرة والعجلة · ملاءمة الصورة للشاشة · الانتقال التلقائي بعد انتهاء الفيديو ·
  تدوير العرض · كتم الصوت · العرض التلقائي للصور بالثواني.

## أين تُحفظ العروض؟

داخل مجلد بيانات المستخدم:

```
%APPDATA%\syaq\syaq-data\sets\
```

كل عرض ملف JSON مستقل. ويمكن **تصديره** كملف `.syaq` لمشاركته أو نقله لجهاز آخر
(من نافذة الحفظ ← «تصدير كملف»)، و**استيراده** من زر ⤓ أعلى الشريط الجانبي.

## بناء نسخة تثبيت (اختياري)

```bash
npm run dist
```

أداة البناء تُجلب عند الطلب فقط (`npx`)، فلا تُثقل التثبيت العادي.

تُنتَج في مجلد `dist` نسختان:

| الملف | ماذا يفعل |
|---|---|
| `Syaq Setup 1.0.0.exe` | مثبِّت: يختار المجلد وينشئ اختصارات سطح المكتب وقائمة ابدأ، ويضيف مزيل تثبيت |
| `Syaq 1.0.0.exe` | نسخة محمولة: تعمل بالنقر مباشرة بلا تثبيت |

حجم كلٍّ منهما نحو ٧٦ م.ب لأنه يحمل محرك Chromium كاملاً. ومثبِّت NSIS ينشئ
اختصارات سطح المكتب وقائمة ابدأ بنفسه، ولا يحتاج الجهاز الهدف إلى Node.js أو Git.

> **لكن انتبه:** التحديث الذاتي من GitHub مبنيّ على نسخة المصدر (مجلد git أو ملفات الفرع).
> النسخة المبنيّة بـ electron-builder تُحزَم داخل `app.asar` فلا تصلح لها هذه الطريقة،
> وتحتاج آلية تحديث أخرى (مثل electron-updater مع GitHub Releases).
> إن كنت تريد التحديث الذاتي كما هو، فالتثبيت بالاستنساخ هو الطريق الصحيح.

## التحديث من GitHub

البرنامج يتابع مستودعه على GitHub بنفسه:

- عند التشغيل يفحص المستودع بهدوء (مرة كل ٦ ساعات على الأكثر حتى لا يُثقل الشبكة)،
  وإن وُجد تحديث ظهرت **نقطة خضراء** على زر «🔄 التحديث» مع تنبيه.
  وزر «🔄 التحديث» نفسه يفحص فوراً متى ضغطته.
- افتح الزر لترى نسختك الحالية وآخر نسخة وعدد التحديثات المتأخّرة وآخر تغيير.
- «تحديث الآن» يجلب الملفات، ثم «إعادة تشغيل البرنامج» لتفعيلها.

يعمل بطريقتين حسب حالة المجلد:

| الحالة | الطريقة |
|---|---|
| المجلد نسخة git (clone) | `git fetch` ثم `git merge --ff-only` |
| المجلد نُزّل كملف ZIP | تنزيل ملفات الفرع من GitHub وكتابتها فوق القديمة |

في الحالتين لا تُمسّ `node_modules` ولا عروضك المحفوظة، وإن تغيّر `package.json`
يُشغَّل `npm install` تلقائياً. وإن وُجد تعديل محلي غير محفوظ في ملفات البرنامج
يتوقّف التحديث ويخبرك، حتى لا يضيع عملك.

### التثبيت على جهاز آخر

المطلوب على الجهاز الجديد: **Node.js** و**Git**.

```bash
git clone https://github.com/fcb999999/siyaq.git
```

ثم داخل المجلد:

```bash
npm install
```

هذا الأمر وحده يكفي: ينزّل المكوّنات، ثم يبني الأيقونة **وينشئ اختصار «سياق»
على سطح المكتب تلقائياً**. بعدها شغّل البرنامج من الأيقونة مباشرة.

- لتعطيل إنشاء الاختصار: `set SYAQ_NO_SHORTCUT=1` قبل `npm install`.
- إن لم تظهر الأيقونة لأي سبب: `npm run shortcut`.
- قد يظهر تحذير `allow-scripts` من npm عند التثبيت؛ هو تحذير فقط ولا يمنع التنزيل.
  وإن منعته نسخة npm عندك فشغّل `npm approve-scripts electron` ثم `npm install` مرة أخرى.

## الشعار

الشعار مرسوم متجهياً في `assets/mark.svg` و`assets/logo.svg`، وتُولَّد منه أيقونتان:

| الملف | الاستعمال | الأمر |
|---|---|---|
| `assets/icon.png` | أيقونة نافذة البرنامج | `npm run icon` |
| `assets/icon.ico` | أيقونة الاختصار ونسخة التثبيت (٧ مقاسات من ١٦ إلى ٢٥٦) | `npm run ico` |

إن أردت استخدام ملف الشعار الأصلي بدل المرسوم، ضع الصورة باسم **`assets/logo.png`**
وسيلتقطها البرنامج تلقائياً عند التشغيل.
