# سياق — عارض المحتوى المتسلسل

> رتّب محتواك.. واعرضه بسياق

برنامج سطح مكتب لويندوز يعرض **الصور والفيديو وملفات PDF والنصوص** في عرض واحد متسلسل،
بحيث تتنقّل بينها بملء الشاشة **دون الخروج من العرض** عند تغيّر نوع الملف.

---

## التشغيل

انقر مرّتين على **`تشغيل سياق.bat`**

أو من سطر الأوامر:

```bash
npm start
```

---

## كيف تستخدمه

1. **أضف المحتوى** — زر «إضافة ملفات» أو «إضافة مجلد»، أو اسحب الملفات وأفلتها في النافذة.
2. **رتّبه** — اسحب البطاقات بالفأرة، أو انقر على **رقم البطاقة** واكتب الرقم الذي تريده فينتقل إليه.
   وهناك ترتيب تلقائي جاهز (بالاسم، بالتاريخ، بالنوع، بالحجم، عكسي، عشوائي).
3. **اعرض** — زر «ابدأ العرض» يفتح ملء الشاشة من أول عنصر (أو من العنصر المحدد).
4. **احفظ** — زر «حفظ العرض» يحفظ الاسم مع الترتيب ومسارات الملفات.
   في أي وقت لاحق افتح البرنامج واضغط «فتح» على العرض من الشريط الجانبي، فيرجع بنفس الترتيب
   ما دامت الملفات في أماكنها. أي ملف نُقل أو حُذف يظهر معلَّماً باللون الأحمر،
   ويمكنك تحديد مكانه الجديد من زر 🔎 على البطاقة.

## اختصارات لوحة المفاتيح داخل العرض

| المفتاح | الوظيفة |
|---|---|
| ◀ يسار | العنصر التالي |
| ▶ يمين | العنصر السابق |
| Space | تشغيل/إيقاف الفيديو، أو الانتقال للتالي في الصور |
| Esc | إنهاء العرض |
| F أو F11 | تبديل ملء الشاشة |
| Home / End | أول عنصر / آخر عنصر |
| G | شبكة المحتوى للانتقال السريع |
| ١…٩ | الانتقال إلى العنصر برقمه |
| + / − / 0 | تكبير / تصغير / إعادة الحجم |
| ↑ / ↓ | رفع / خفض الصوت |
| M | كتم الصوت |

> اتجاه الأسهم قابل للعكس من **الإعدادات** إن كنت تفضّل النمط الإنجليزي.

### الفأرة
- **النقر** على نصف الشاشة الأيسر = التالي، والأيمن = السابق (قابل للتغيير من الإعدادات).
- **الزر الأيمن** = العنصر السابق.
- **العجلة** = تنقّل، أو تكبير الصورة — حسب إعدادك.
- في ملفات PDF والنصوص تُعطَّل مناطق النقر تلقائياً حتى تتصفّح المستند براحة.

### اختصارات خارج العرض
`Enter` بدء العرض · `Delete` إزالة المحدد · `Ctrl+S` حفظ · `Ctrl+A` تحديد الكل ·
`Ctrl + سهم` تحريك العنصر المحدد في الترتيب

## الإعدادات

اتجاه التنقل · سلوك النقر والعجلة · ملاءمة الصورة للشاشة · تشغيل الفيديو تلقائياً ·
الانتقال التلقائي بعد انتهاء الفيديو · تدوير العرض · كتم الصوت · العرض التلقائي للصور بالثواني.

## الصيغ المدعومة

| النوع | الصيغ |
|---|---|
| صور | jpg, png, gif, webp, bmp, avif, svg, ico |
| فيديو | mp4, webm, m4v, mov, ogv *(وبعض الصيغ الأخرى حسب دعم النظام)* |
| صوت | mp3, wav, m4a, aac, flac, opus, ogg |
| مستندات | pdf (يُعرض داخل البرنامج)، txt, md, csv, json وملفات الكود |
| أخرى | docx, xlsx, pptx… تظهر كبطاقة مع زر فتحها بالبرنامج الافتراضي |

## أين تُحفظ العروض؟

داخل مجلد بيانات المستخدم:

```
%APPDATA%\syaq\syaq-data\sets\
```

كل عرض ملف JSON مستقل. ويمكن **تصديره** كملف `.syaq` لمشاركته أو نقله لجهاز آخر
(من نافذة الحفظ ← «تصدير كملف»)، و**استيراده** من زر ⤓ أعلى الشريط الجانبي.

## بناء نسخة تثبيت (اختياري)

```bash
npm install --save-dev electron-builder
npm run dist
```

تُنتَج النسخة في مجلد `dist` (مثبِّت NSIS ونسخة محمولة).

## الشعار

الشعار مرسوم متجهياً في `assets/mark.svg` و`assets/logo.svg`، وأيقونة البرنامج
مولّدة منه في `assets/icon.png` (لإعادة توليدها: `npm run icon`).

إن أردت استخدام ملف الشعار الأصلي بدل المرسوم، ضع الصورة باسم **`assets/logo.png`**
وسيلتقطها البرنامج تلقائياً عند التشغيل.
